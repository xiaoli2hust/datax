# ADR-0001：V1 范围与非目标

- 状态：Accepted
- 日期：2026-07-30

## 背景

原始文档同时出现数据源、调度、DAG、插件市场和 AI，无法形成可实现、可验收的第一版。

## 决策

V1 只交付单组织多项目、MySQL 8/PostgreSQL 15 认证矩阵、离线批同步、手动触发、直连字段映射、`insert-only`、真实 DataX 执行、日志状态和审计。

AI、调度、DAG、告警、插件市场、任意 SQL、CDC、多租户和 HA 均排除。

## 后果

- 可以用一个真实纵向链路客观验收。
- UI 和数据模型不为未实现功能显示可操作入口。
- 后续能力必须新建 ADR、威胁模型、契约和测试，不能以参数开关绕过。
